## Local Setup

For macOS with zsh, install NVM first if needed. The project requires Node.js 22.12+.

```zsh
nvm install
nvm use
corepack yarn install
corepack yarn dev
```

Open the local URL shown by Vite. To verify a production build:

```zsh
corepack yarn build
```
